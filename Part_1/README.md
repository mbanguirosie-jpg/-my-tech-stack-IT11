# Calculs manuels - Variante 6
## Conversion RGB(255, 128, 0) → HEX

### Méthode de conversion:

**R = 255**
- 255 ÷ 16 = 15 reste 15
- 15₁₆ = F
- Donc: 255₁₀ = FF₁₆

**G = 128**
- 128 ÷ 16 = 8 reste 0
- 8₁₆ = 8
- 0₁₆ = 0
- Donc: 128₁₀ = 80₁₆

**B = 0**
- 0 ÷ 16 = 0 reste 0
- Donc: 0₁₀ = 00₁₆

### Résultat final:
RGB(255, 128, 0) = **#FF8000**
